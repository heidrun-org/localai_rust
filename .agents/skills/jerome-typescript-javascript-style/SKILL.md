# Jérôme Étienne’s personal TypeScript and JavaScript coding style

This skill describes Jérôme Étienne’s own way of coding. These are his personal preferences, not a general TypeScript or JavaScript standard.

Before creating or editing a matching source file, read [the personal coding style rules](references/typescript-javascript-style.md) in full and apply the relevant rules to the requested changes. The rules cover conditionals, control flow, types, documentation, naming, formatting, HTML construction, code organization, section separators, and standalone JavaScript scripts.

The rules come from Jérôme Étienne’s Claude Code user configuration, originally stored in `~/.claude/rules/typescript-javascript-style.md`. The reference file contains the original rules with changes made only on Jérôme Étienne’s explicit instructions. The full rules are included in this skill; using the skill does not require access to that configuration file. Installing this skill does not change the original user configuration.
